# Task-3
The Book Manager is a full-stack web application built using HTML, CSS, JavaScript, and Node.js with Express. The application allows users to add, view, update, and delete books through a clean and responsive user interface. The frontend communicates with a RESTful API running on a local Express server, demonstrating complete CRUD (Create, Read, Update, Delete) functionality.

The frontend is designed using modern UI styling with card layouts, soft pastel colors, hover effects, and responsive design. JavaScript’s Fetch API is used to send HTTP requests (GET, POST, PUT, DELETE) to the backend server. The backend is developed using Express.js and includes API routes to manage books stored in an in-memory array, along with proper status codes and error handling.

Through this project, I strengthened my understanding of REST APIs, client-server communication, asynchronous JavaScript, CRUD operations, middleware usage (CORS and JSON parsing), and full-stack development fundamentals. This project helped me gain practical experience in connecting a frontend interface with a backend server and managing application data efficiently.
